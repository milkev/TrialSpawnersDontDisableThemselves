### Trial Spawns Dont Disable Themselves (TSDDT)
In short, all it does is stop trial spawners from wiping their spawn data entry. This stops custom made or non-mojang-approved trials chambers from only being usable once.

### TSDDT and Neoforge!
Playing on Neoforge but want to use TSDDT? Look no further than [Sinytra](https://www.curseforge.com/minecraft/mc-mods/sinytra-connector)! TSDDT has full compatability with Sinytra for playing on Neoforge.
